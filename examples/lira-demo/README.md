# Lira demo student

A fictional student, "Sam", showing what the agent reads and what it produces. Nothing here is a real student.

```
Students/Sam/
  Sam.md              profile: interests, concept sequence, recent errors
  sounds.md           abbreviated sound catalog with Known flags
  sight-words.md      abbreviated sight word list with Known flags
  lesson-plans/
    2026-01-12-ck.md  abbreviated sample plan
```

Sam knows consonants, short vowels, sh, ch and th. Sam does not know ck, floss, blends, silent e, vowel teams, r-controlled vowels or any syllable division, so every word in the sample plan is one syllable and uses only those sounds.

The sample plan is a hand-written excerpt to show the shape and the constraints. In the app, plans are generated by the model, checked twice, and exported to PDF.

Things to look for in the sample:

- Auditory drill lists error sounds first, then review sounds, each with only the spellings Sam knows.
- Blending uses nonsense words built for each error, with minimal pairs.
- No content word appears in two sections.
- The new concept (ck) is kept out of the oral reading passage, which practices what is already secure.
