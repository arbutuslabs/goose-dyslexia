# Sounds Reference

Orton-Gillingham scope and sequence, in teaching order. Mark `Known` as `true` once the student has mastered the item.

**Sequence column.** Row order is the DEFAULT teaching sequence, not the only valid one.
Rows marked `flex: may precede VCCV` are the 1-syllable VCe block — many teachers introduce
these before moving to 2-syllable VCCV work, and either order is fine. The row marked
`needs VCCV + VCe` is the merge point: it requires both, whichever came first.
For what a given student learned most recently, the **profile's Concept sequence is the
authority**, not this file's row order.
